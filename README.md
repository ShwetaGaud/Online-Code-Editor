# Online Code Editor

A web-based online code editor that supports multiple programming languages including Python, Java, JavaScript, C++, and PHP.

## Features

- Multi-language code execution
- Syntax highlighting
- Real-time error handling
- File upload and download
- Browser-based coding environment

## Technologies Used

- Django
- Ace Editor
- Python
- HTML
- CSS
- JavaScript

## Supported Languages

- Python
- Java
- JavaScript
- C++
- PHP

## Project Overview

This project provides an interactive web-based environment where users can write, edit, and execute code in multiple programming languages without using a traditional desktop IDE.
